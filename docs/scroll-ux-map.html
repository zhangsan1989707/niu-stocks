收益：涨停 20 列大表滚动时始终看得见列名 | 代价：改 3 处 CSS + 容器高度自适应

涨停页分页 / 加载更多 已完成

92 行全部渲染，DOM 重、滚动长。改为每页 30 行 + "加载更多"按钮（保留当前全部筛选排序逻辑）。

收益：渲染提速、滚动距离减 2/3、移动端流畅度明显提升

快捷键滚动 P0
