# 牛股体检站（Leostocks）

本地运行的 A 股技术面分析 Web 应用。给个股做"技术体检"——健康分、灯色（红/黄/绿）、四方会诊（蜡烛短线 / 趋势破位 / 摆动动量 / 图表中线）、多周期共振，并内置智能选股引擎与回验。

技术面分析，**不构成任何投资建议**。

## 特性

- 个股体检：健康分、灯色、破位检测、经典图表形态识别、墨菲摆动指标组
- 智能选股：三层引擎（硬过滤 → 多策略信号 → 加权 TopK + 前向回验）
- 多周期共振：日 / 周 / 月线趋势聚合
- 工作台：自选股、持仓/交易记录、价格提醒、笔记、规则库
- 数据来源：东方财富（新浪降级），全程无账号、无付费

## 技术栈

纯 Node.js（无框架，手写 HTTP 服务）+ 原生前端（vanilla JS + hash 路由），零构建步骤。

## 运行

```bash
npm install
npm start          # 默认 http://localhost:8080
```
